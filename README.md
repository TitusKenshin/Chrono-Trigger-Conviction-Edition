# Chrono Trigger - Conviction Edition

**Small patches for Chrono Trigger that 1) graphically alter Ayla's sprites to have more decent attire while still maintaining the feel of the character, and 2) change dialog in Magus's Castle to remove strange references surrounding the mage Flea.**

Patches can be applied using Marc Robledo's Rom Patcher JS, located here: https://www.romhacking.net/patch/

Changelog:

v1 - Inital release

v2 - Edited more of Ayla's sprites for greater accuracy

v3 - Edited Ayla's overworld sprites as well
